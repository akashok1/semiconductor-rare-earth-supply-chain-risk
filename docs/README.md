# docs

Numbered in reading order: `00` brief, `01` charter, `02` BRD (business requirements), `03` FRD (functional requirements), `04` data dictionary, `05` traceability matrix, `06` UAT plan, `07` assumptions and limitations.

- `00` to `02` are baselined: written before the build and kept as they were. Where they differ from the code, `07` is the current record.
- `FINDINGS.md` logs each place the code contradicted a baselined doc.
- `verification/` holds the pre-build checks on sources, transport mode and routing method. Historical.
