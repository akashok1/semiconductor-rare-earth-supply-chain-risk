**Caveat:** "nearest vertex" is coarser than "nearest point on the route line." Vertex spacing on long open-ocean segments can run into the hundreds of km, so a route can pass close to a chokepoint without any single vertex landing inside the threshold. A miss here is not proof the route doesn't pass near that chokepoint.
